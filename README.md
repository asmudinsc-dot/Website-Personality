# 🌟 Portofolio Web 3D Profesional — Asmudin

Website portofolio interaktif profesional berdimensi 3D dengan visual **Three.js & WebGL**, dirancang khusus untuk **Asmudin** dengan spesialisasi utama di bidang **HTML, CSS, JavaScript, MySQL, CodeIgniter, dan Sistem Informasi**.

---

## 👨‍💻 Profil Pengembang

- **Nama**: Asmudin
- **Spesialisasi**: Web Developer & Spesialis Sistem Informasi
- **Keahlian Utama**:
  - **Framework & Backend**: CodeIgniter (PHP) — MVC, Validasi Form, CSRF, REST API
  - **Basis Data**: MySQL — Perancangan ERD, Relasi Foreign Key, Query JOIN Kompleks, Optimasi Indexing
  - **Frontend**: HTML5 Semantik, CSS3 Responsif (Flexbox/Grid/Glassmorphism), JavaScript (ES6+ & AJAX)
  - **Sistem Informasi**: Analisis Proses Bisnis, Modul CRUD, Manajemen Hak Akses, Ekspor PDF/Excel
  - **Grafis Web Interaktif**: Three.js & WebGL 3D

---

## 🚀 Fitur Utama Portofolio

1. **Inti Visual 3D Interaktif (Three.js & WebGL Engine)**:
   - **Quantum Core 3D Mesh**: Objek geometris spasial futuristik dengan cincin gimbal dan satelit berputar.
   - **Starfield Galaxy**: 1.800+ partikel antariksa bereaksi terhadap kursor mouse dan scroll halaman.
   - **Interaksi Drag-to-Rotate 360°**: Pengunjung dapat memutar kamera 3D ke berbagai sudut dengan inersia halus.
   - **Studio Lab 3D**: Kendali langsung untuk mengubah bentuk geometri (*Quantum Core*, *Torus Knot*, *Cyber Crystal*, *Energy Sphere*), kecepatan rotasi, serta mode wireframe.

2. **Karya & Proyek Sistem Informasi (Studi Kasus)**:
   - **SIM-Aset 3D Enterprise**: Sistem manajemen aset & inventaris kantor dengan denah ruangan 3D interaktif (CodeIgniter 4, MySQL, Three.js, Bootstrap 5).
   - **SIP-Desa**: Sistem pelayanan kependudukan terpadu, permohonan surat online, dan arsip digital (CodeIgniter, MySQL, AJAX, DomPDF).
   - **SIAKAD Terpadu**: Portal akademik KRS, absensi, rekap nilai IPK otomatis, dan grafik statistik (PHP CodeIgniter, MySQL, Chart.js).
   - **KlinikCare**: Sistem informasi rekam medis, antrean poli real-time, billing kasir, dan apotek (CodeIgniter, MySQL, JavaScript AJAX).

3. **Desain & Interaktivitas Modern**:
   - **3D Perspective Card Tilt**: Efek kartu melayang dengan rotasi 3D dan kilauan specular highlight saat disentuh mouse.
   - **Dynamic Role Typing**: Animasi teks mengetik otomatis nama keahlian Asmudin di bagian Hero.
   - **4 Pilihan Warna Aksen**: Sinkronisasi warna tema (*Cyber Violet*, *Electric Cyan*, *Neon Emerald*, *Solar Amber*) dengan pencahayaan 3D secara instan.
   - **Efek Suara Sci-Fi Sintesis (Web Audio API)**: Efek audio klik futuristik tanpa beban download file MP3.
   - **Filter Kategori Keahlian**: Tab filter untuk memilah keahlian CodeIgniter, Database, Frontend, dan Sistem Informasi.
   - **Modal Rincian Kasus Lengkap**: Menampilkan tantangan, solusi arsitektur, dan metrik keberhasilan sistem.

---

## ⚡ Cara Menjalankan

Cukup klik dua kali berkas **`buka_portfolio.bat`** atau berkas **`index.html`** di dalam folder `portfolio-3d`. Halaman portofolio akan langsung terbuka di browser Anda tanpa perlu konfigurasi tambahan.

---

## 📂 Struktur Berkas

```
portfolio-3d/
├── index.html            <- Struktur HTML5 portofolio Asmudin

├── css/

└── js/

    ├── audio-fx.js       <- Sintesis suara interaktif Web Audio API

```
