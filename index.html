Halo! Saya Asmudin, seorang Web Developer dan Pengembang Sistem Informasi yang berfokus pada pembangunan aplikasi web berbasis HTML, CSS, JavaScript, MySQL, dan framework CodeIgniter, dipadukan dengan sentuhan visual grafis 3D interaktif.

Saya berpengalaman merancang arsitektur sistem informasi dari hulu ke hilir: mulai dari perancangan skema database relasional MySQL yang teroptimasi, alur logika proses bisnis (CRUD dinamis, otentikasi multi-level hak akses, validasi data, pelaporan PDF/Excel), hingga antarmuka pengguna responsif yang interaktif dan mudah dioperasikan di berbagai perangkat.

Sistem Informasi Terintegrasi

Framework CodeIgniter

Pola arsitektur MVC yang bersih, routing terstruktur, modul CRUD cepat, proteksi CSRF, sanitasi input, dan pencegahan SQL Injection.

HTML, CSS, JS & 3D Web

Struktur semantik HTML5, styling CSS3 responsif, interaktivitas AJAX/DOM JavaScript, dan visual spasial 3D WebGL modern.
